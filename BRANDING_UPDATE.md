# AI DataFlow Branding

The app uses the AI DataFlow red/black brand system:

- Primary Red: `#E63946`
- Primary Red Dark: `#C1121F`
- Secondary Red: `#FF5A5F`
- Accent Red: `#FF6B6B`
- Black: `#1A1A1A`
- Dark Gray: `#2D2D2D`
- Success Green: `#00cc66`
- Warning Orange: `#ff9900`

Auth pages use the full logo image. Dashboard pages use the compact red "AI" navigation mark with the DataFlow wordmark.
